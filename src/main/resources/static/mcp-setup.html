🔌 MCP GraphQL Wrapper

Connect Claude Desktop Directly to Enterfind's GraphQL API

What is this?

The MCP GraphQL Wrapper is a Node.js script that allows Claude Desktop to connect directly to Enterfind's GraphQL API, without requiring a hosted MCP server endpoint. The wrapper implements the MCP protocol locally and translates tool calls to GraphQL queries.

📌 Use Case: You have an Enterfind server with GraphQL API (e.g., https://your-enterfind-instance.example.com/graphql) and want to use it with Claude Desktop. This wrapper bridges stdio (used by Claude) directly to GraphQL—no /mcp endpoint needed!
✨ Features:
  • Stateless design - No token storage; AI manages authentication via GraphQL variables
  • Schema introspection - Discover available queries, mutations, and authentication requirements
  • Direct GraphQL execution - Run any query or mutation with pass-through variables
  • No server changes needed - Works with any GraphQL endpoint

How It Works

Claude Desktop (stdio / JSON-RPC)
    ↕️
MCP GraphQL Wrapper (implements MCP protocol)
    ↕️
Enterfind GraphQL API (/graphql)

The wrapper implements the MCP protocol locally, exposing two tools that translate to GraphQL operations:

  • introspect_graphql_schema - Get the GraphQL schema to discover available queries, mutations, and authentication requirements
  • execute_graphql - Run any GraphQL query or mutation (pass token as a variable for authenticated operations)

Setup Instructions

1Download the Script

Download mcp-graphql-wrapper.js using the button above and save it to a convenient location.

2Test the Connection

Verify the wrapper can communicate with your server:

echo '{"jsonrpc":"2.0","method":"initialize","params":{},"id":1}' | \
  node mcp-graphql-wrapper.js https://your-server-url/graphql

You should see a JSON response with server information including protocol version.

3Configure Claude Desktop

🍎 macOS
🪟 Windows

macOS Configuration:

1. Open the configuration file:

nano ~/Library/Application\ Support/Claude/claude_desktop_config.json

2. Add this configuration:

{
  "mcpServers": {
    "enterfind": {
      "command": "node",
      "args": [
        "/path/to/mcp-graphql-wrapper.js",
        "https://your-server-url/graphql"
      ]
    }
  }
}

3. Save and exit (Ctrl+X, then Y, then Enter)

Windows Configuration:

1. Open the configuration file:

%APPDATA%\Claude\claude_desktop_config.json

2. Add this configuration:

{
  "mcpServers": {
    "enterfind": {
      "command": "node",
      "args": [
        "C:\\path\\to\\mcp-graphql-wrapper.js",
        "https://your-server-url/graphql"
      ]
    }
  }
}

3. Save the file

4Restart Claude Desktop

Completely quit Claude Desktop and restart it. Your MCP server should now be available!

5Verify Connection

✅ Success indicators:
  • Look for the MCP/tools indicator in Claude Desktop
  • Your server name should appear in the list of connected servers
  • Your tools should be available to use in conversations

Troubleshooting

Wrapper won't start

Check Claude Desktop logs:

  • macOS: ~/Library/Logs/Claude/mcp*.log
  • Windows: %APPDATA%\Claude\logs\mcp*.log

Connection refused

  • Verify your server is running
  • Check the server URL in your configuration
  • Ensure your firewall allows the connection

SSL certificate errors

The wrapper accepts self-signed certificates by default. For production use with valid certificates, you may need to modify the script.

Important Notes

⚠️ Security: This wrapper is designed for local/trusted network use. It bypasses SSL certificate verification for self-signed certificates. Do not use this for untrusted or internet-accessible servers.
💡 For Internet-Accessible Servers: If you plan to make your MCP server publicly accessible on the internet, you should implement OAuth 2.1 authentication and use Claude Desktop's "Add custom connector" UI instead of this wrapper.

Authentication

If your Enterfind server requires authentication, the wrapper uses a stateless approach where the AI manages tokens via GraphQL:

🔐 Authentication Flow

  1. Ask Claude to introspect the schema: "What operations are available?"
  2. Check if auth is required: Claude calls isAuthenticationRequired query via execute_graphql
  3. If required, provide your credentials: "Login with nickname 'myuser' and TOTP code '123456'"
  4. Claude calls the login mutation and receives a token
  5. For subsequent authenticated operations, Claude includes the token as a GraphQL variable: {"token": "your-token"}
💡 Stateless Design: The wrapper does not store tokens—the AI is responsible for including the token in each authenticated request. This makes authentication explicit and discoverable via GraphQL introspection.
